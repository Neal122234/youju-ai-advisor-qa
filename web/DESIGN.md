# 有据 · DESIGN.md

本项目前端（落地页 / App 内问答 / 运营后台）的统一视觉依据。结构取自 design-md-library 的 `playful/toss`（Toss：成熟移动金融产品，旗下有券商业务），后台密度对标 Stripe Dashboard。唯一改动：品牌色由 Toss Blue 换为**券商红**，贴合国内券商 App 的用色习惯。实现见 `web/src/styles.css` 顶部令牌。

## 1. 气质

像一个已经上线多年的券商 App 内页：白底、一种品牌红、中性灰阶、平铺无装饰。信息层级靠字号、字重、留白和分隔线，不靠框线和阴影。文案像 App 和官网，直接说能做什么，不解释自己怎么设计。

## 3. 字体

- 字族：系统字体 `-apple-system, "PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Microsoft YaHei"`；等宽 `"SF Mono", ui-monospace, Menlo`，只用于工单号、日志 ID、doc_key。
- 字号：12 / 13 / 14 / 15 / 17 / 20 / 24 / 32 / 44。
- 字重：只用 400 和 600。
- 数字：全站 `font-variant-numeric: tabular-nums`。

## 4. 组件

- **按钮**：主按钮品牌红实底、白字、圆角 8px、高 36（小号 28）；次按钮 `--fill` 底、`--ink` 字；文字按钮无底。无投影、无上浮。危险操作只在确认弹窗里出现实底 `--neg` 按钮。
- **输入框**：`--fill` 底、无描边、圆角 10px；聚焦 2px 品牌红描边。
- **列表**：一律用 1px 分隔线分行，不包卡片。后台表格行高 44，表头 12px `--ink-3`。
- **状态**：色点（6px 圆点）+ 文字。
- **对话（App）**：顶部导航栏 48 高白底，标题居中；对话区 `--canvas` 灰底；用户气泡品牌红、白字，圆角 16、右下 4；助手回答白底、圆角 16、左上 4，无阴影；底部输入栏白底，圆角输入框 + 圆形发送键。欢迎态给分组常见问题（分段切换 + 分隔线列表）。来源用底部抽屉（圆角 16 顶部、把手条）。
- **后台（Stripe 密度）**：左侧导航白底、1px 右分隔线，当前项 `--fill` 底 + `--ink` 字；页面标题 20/600；指标区为一排数字（之间用分隔线），不用卡片；面板只用标题 + 顶部分隔线分区。
- **弹窗**：白底、圆角 12、`0 16px 48px rgba(25,31,40,.16)`；移动端底部抽屉。

## 5. 布局

- 4px 基准：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 落地页：品牌顶栏 → 首屏左文右图（右侧为真组件渲染的手机界面）→ 对用户 / 对运营两栏 → 页脚。左对齐，不做居中对称 hero。
- 必须适配 1389×713 矮窗口与 375 宽手机，无横向滚动。

## 6. 层级

只有浮层有阴影：气泡预览 / 下拉 `0 8px 24px rgba(25,31,40,.10)`，弹窗与抽屉 `0 16px 48px rgba(25,31,40,.16)`。页面内容零阴影。

## 7. Do / Don't

**Do**：一种品牌红；分隔线分行；等宽数字；底部抽屉；短句、动词开头的按钮文案（「起草知识」「发布」「回滚」）。

**Don't**：卡片套卡片；处处大圆角 + 浅阴影；满屏彩色胶囊；图标 + 粗体开头的说明列表；步骤流程讲解图；抽象示意图；渐变；emoji；超过两种字重；第二个品牌色。

## 8. Agent Prompt Guide

Bias：白底、券商红 `#e5352b` 单一品牌色、灰阶中性、8/10/12/16 圆角、分隔线列表、tabular-nums、底部抽屉、Stripe 式后台表格。
Reject：灰蓝通用配色、阴影卡片网格、彩色 badge 墙、讲解式流程图、居中模板 hero、emoji、自述设计思路的文案。
